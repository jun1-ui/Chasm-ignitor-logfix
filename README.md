# Chasm-ignitor-logfix
비공식 수정본입니다… 캐즘 제작자 여러분들 정말 감사합니다

🔷 결정화 캐즘 이그나이터 비공식 수정본 배포

최근 크랙 업데이트 이후 기존 이그나이터의 채팅 로그 조회 및 일부 기능이 정상적으로 작동하지 않는 문제를 수정한 버전입니다.

🛠️ 주요 수정 사항

* 크랙 채팅 로그 조회 방식 수정
* 다중 페이지 로그 조회 및 완료된 대화 턴 처리
* 크랙 UI 변경에 따른 이그나이터 메뉴 버튼 위치 수정
* 기존 채팅 로그 기반 요약 기능 호환성 개선

📥 설치 방법

1. Tampermonkey 설치
2. 기존 이그나이터 비활성화 또는 삭제
3. 아래 설치 링크에서 수정본 설치
4. 크랙 페이지 새로고침 후 이그나이터 메뉴 확인

설치 링크: (GitHub 링크 추가)

⚠️ 주의사항

* 본 스크립트는 비공식 사용자 수정본입니다.
* 원본 개발팀에서 공식적으로 배포하는 버전이 아닙니다.
* 크랙 업데이트에 따라 일부 기능이 다시 작동하지 않을 수 있습니다.
* Gemini API 이용 시 개인 API 키가 필요하며, API 사용량에 따라 비용이 발생할 수 있습니다.
* 채팅 로그와 설정에 포함된 정보가 선택한 AI 서비스로 전송될 수 있습니다.
